# Designs

A design record says what a change will be and why it takes that shape. Write one when the shape has to be decided before the work starts. Use the [design record template](../templates/design.md).

Name a record `<UTC datetime>_<kind>_<name>.md`, for example `2026-10-18T14-30-00Z_design_mcpx_from_code.md`. Link it from the roadmap row it belongs to. Append later changes as dated sections and leave the earlier text alone.

[`ARCHITECTURE.md`](../../ARCHITECTURE.md) describes the repo as it is today. Update it when a design ships.
